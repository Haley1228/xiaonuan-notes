# 背景

- alignment：对齐要求模态间的时间与空间的同步性
- fusion：把对齐后的特征融合到一个统一的表示
- 现有的方法通常单独处理对齐和融合，导致效果不好
## 问题

1. 时间维度没有对齐
    - 同一时间戳下从不同模态提取的特征可能无法准确对应，导致时间维度上失对齐
    - 从而导致含义混淆，削弱模型准确推断情感的能力
2. 语义空间没有对齐，这被称为模态异质性
    - 对比学习实现

# 相关工作

- 时间对齐和语义对齐
    通过对比学习实现语义对齐
- 多模态融合
    早期融合与晚期融合
- 对比学习
